# Imagem do Hero

> **Upload rápido:** nesta pasta, selecione **Add file → Upload files** e anexe
> a imagem original com o nome `hero-azevedo.png`.

O arquivo binário da imagem não acompanha este pull request. Depois que o PR
for criado, adicione manualmente a imagem original, sem renomeá-la, neste
caminho exato:

```text
assets/images/hero-azevedo.png
```

A Home já referencia esse endereço no preload de `index.html` e no background
de `assets/css/home.css`. Não substitua a imagem por outro arquivo ou formato.
