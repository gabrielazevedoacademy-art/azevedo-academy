# Atalho para adicionar a imagem do Hero

## [Abrir a pasta de destino da imagem](assets/images/)

Dentro dessa pasta, use **Add file → Upload files** e anexe a imagem original
com este nome exato:

```text
hero-azevedo.png
```

Depois, confirme o upload. A Home já está configurada para carregar o arquivo
automaticamente; não é necessário editar o HTML ou o CSS.
