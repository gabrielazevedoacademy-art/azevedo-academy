O time de design do GitHub lançou em 28 de outubro o **Replica**, uma ferramenta de código aberto que transforma uma descrição em texto num **protótipo interativo**. A diferença para outros geradores de tela é que ele usa o **design system do seu próprio produto**: componentes, padrões e documentação que o time já tem.

## Como funciona

Os designers definem as orientações uma vez. A partir daí, qualquer pessoa do time descreve o que quer no app do GitHub Copilot e vê o protótipo ao lado da conversa, podendo testar e pedir ajustes. O resultado já sai com a cara do produto, em vez de uma tela genérica que depois precisa ser refeita.

Para compartilhar, existe o **Replica Hub**, um espaço opcional que o próprio time hospeda, onde os protótipos ficam publicados e os colegas deixam comentários.

## Licença e como começar

O Replica usa licença **MIT** e pode rodar no seu computador seguindo as instruções do [repositório no GitHub](https://github.com/github/replica). Como todo protótipo feito com IA, o resultado serve para explorar ideias e validar fluxos; ainda precisa de revisão antes de virar produto de verdade.

## O que muda pra quem cria

Para designers e quem trabalha com produto digital, o tempo entre a ideia e algo clicável cai bastante, sem perder a identidade visual. Para quem cria conteúdo, é uma boa referência de para onde as ferramentas estão indo: IA que respeita a sua marca, em vez de inventar um estilo novo a cada pedido.
